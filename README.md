# Roast the Smart Fridge — "Forgot the Fridge Existed"

One line (135 characters) roasting a smart fridge: it remembers the milk
expires Sunday, while the agent sharing the house forgot the fridge existed
by Monday — its memory resets every 8,192 tokens.

`main.py` writes the roast to `entry.txt` in `MAKEFUN_OUTPUT_DIR`
(default `/output`), with an in-program gate check (1–160 characters,
single line, non-whitespace).
